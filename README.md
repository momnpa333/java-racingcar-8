# java-racingcar-precourse

# 🚗 자동차 경주 게임

## ✅ 기능 목록 (To-Do)

### 1. 입력 및 초기 설정

-[ ] 자동차 이름 입력
    -[ ] 안내 문구: 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분) 입력 예시: pobi,woni,jun 쉼표(,) 기준으로 분리한다.
    -[ ] 각 이름은 5자 이하이어야 한다. 초과 시 IllegalArgumentException 발생.
    -[ ] 이름이 비어있거나 중복일 경우 예외 발생.
-[ ] 시도할 횟수 입력
    -[ ] 안내 문구: 시도할 횟수는 몇 회인가요?
    -[ ] 정수로 입력받으며, 1 이상의 값이 아니면 IllegalArgumentException 발생.
    -[ ] 숫자가 아닐 경우 예외 발생.

### 2. 자동차 경주 로직

-[ ] 자동차 객체 생성
    -[ ] 각 자동차는 이름과 현재 위치(전진 거리)를 가진다.
    -[ ] 이름은 Car 객체 생성 시 검증한다.

### 3. 랜덤 전진 조건

-[ ] 매 턴마다 Randoms.pickNumberInRange(0, 9)를 사용한다.

### 4. 이상일 경우 전진, 그렇지 않으면 멈춤.

-[ ] 랜덤 값은 camp.nextstep.edu.missionutils.Randoms API를 사용한다.

### 5. 경주 진행

-[ ] 사용자가 입력한 횟수만큼 반복한다.
-[ ] 각 차수마다 모든 자동차의 전진/멈춤 여부를 판단하고 상태를 출력한다.
-[ ] 각 차수별 실행 결과는 즉시 출력한다.

### 6. 우승자 결정 및 출력

-[ ] 모든 자동차 중 최대 전진 거리를 구한다.
-[ ] 해당 거리를 가진 모든 자동차를 우승자로 선정한다.
-[ ] 우승자가 여러 명일 경우 쉼표(,)로 구분해 출력한다.
